Eigengrau

I worked on this project as part of Abertay's Accessibili-Tay Game Jam, in a team of 5 people, including programmers and designers.

Eigengra is a parser game about exploring a dark house and experiencing the objects in it without sight. It has high contrast text, text to speech, and speech to text options for accessibility.

Programming Responsibilites

Parser

I implemented the input functionality and handling for the game.

Gameplay Logic

I also handled the responses to gameplay actions, programming the logic for what should happen when the player types in certain words.
