Gabaghoul's Ghostly Adventure

I worked on this project as part of a team of four programmers, in a class about games programming and system architecture. This class involved developing for console, specifically using PS5 devkits and software.

Programming Responsibilites

Audio

I handled the audio implementation for the project. This involved using Playstation's audio middleware to create sound banks, and then implementing those sounds in a way that made the game feel responsive.

Haptic Feedback

I also handled implementating controller vibrations, in order to give the player quick and enjoyable feedback upon taking actions.
