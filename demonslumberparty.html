Programming Responsibilities

Pillow Fighting

A simple, fighting game style microgame. Due to the simplicity of the combat, with it only being 15 seconds long, I focused on making it feel good to play, and went through a lot of playtesting and tweaking to make it feel nice. I'm extremely proud of of this microgame ended up!

Window Golf

A timing based microgame. This game went through some iteration- initially, the player had to select windows using the arrow keys, but we noticed in playtesting that players got confused. Because of this, I simplified the game down to one control. Handling the trajectories of the balls also went through some iteration before I settled on pre-calculated values in order to keep the short game easy to pick up.

Makeover

A 2000s style girly makeover game (with a demon). This was really fun to make, and I worked with one of our designers to create the mask drawing and make it smooth.

Card Game

A simple memory game.

Overall, my favourite part of this project was getting to work on so many small mechanics and systems, from prototype to polish. Working with my fellow programmer and designers to bring everything together, and make everything cohesive, fun and polished was a really interesting challenge!
